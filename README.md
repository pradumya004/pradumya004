SDE-1 at **SpringWorks**, building automation for a background-verification platform. Before that I built [getmaxhealthcare.com](https://www.getmaxhealthcare.com) and internal tools at GetMax Solutions, a US healthcare RCM company. Bengaluru, open to remote.

### Production work

- **Reference-check automation.** Auto-initiation, a 24h follow-up cadence, an in-product verifier form, and LLM classification of manager email replies on AWS Bedrock. 86% of checks now start without a human, manual tasks fell from 116 to 14 a day, turnaround dropped 31%.
- **WhatsApp on Meta Cloud API.** Proposed and built it: send pipeline, webhooks, BullMQ queues, template sync, an agent inbox and an AI reply classifier. 11K+ messages in the first 10 weeks, 80-91% delivered, about 90% of replies routed with no agent.
- **AI in the verification pipeline.** A YOLO + OpenCV document auto-crop service (2.25x recall on a 411-image production set) and LLM classification of free-text input that fails closed to a human.
