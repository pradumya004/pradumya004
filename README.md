### In production

- **Reference-check automation.** Auto-initiation, a 24h follow-up cadence, an in-product verifier form, and LLM classification of manager email replies on AWS Bedrock that routes each one to grading, clearance or follow-up.

- **AI in the verification pipeline.** A YOLO + OpenCV document auto-crop service (2.25x recall on a 411-image production set) and LLM classification of free text that fails closed to a human.
